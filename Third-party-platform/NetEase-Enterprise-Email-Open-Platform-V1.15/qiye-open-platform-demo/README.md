### 模块划分
#### token
对外接口获取token的代码参考

#### api
常用对外开放接口的代码参考，依赖于`token`

#### demo
提供SDK的使用demo，在服务端程序中实例化并持有SDK实例，每次token过期都重新更新并设置token
尽量在token有效期内，直接调用。为避免资源浪费，后期会限制token的获取次数，以免造成接口异常

#### sso
企业邮，单点登录的url生成demo

#### util
可能用到的一些类，目前对接需要用到的只有RSATool，用于产生单点登录所需的PKCS1签名值
