# 业务流程梳理

1. 用户扫码二维码获取预约入口网址（h5），进入H5页面
2. 判断是否是新用户访问
   - 判断依据：浏览器localStorage中visitor_id是否存在。不存在，代表新用户；存在，提交visitor_id到后台查询是否存在这个visitor_id对应的用户信息，如果未查询到代表新用户，查询到了代表老用户。
   新用户：自动生成visitor_id。
   老用户：把查询到的信息反馈到前端。
   - 逻辑：
     1. 是新用户，跳转《用户信息》页面，填写用户相关信息，提交后台（包括新生成的visitor_id）。
     2. 不是新用户，
        判断当前日期是否存在申请日期范围内的审批记录。
           1. 如果有，
               - 状态（未审批、通过）:跳转《访客预约列表》页面
               - 状态（拒绝）：
                 - 审批记录数<3: 跳转《申请单》页面。（提醒用户，存在审批人拒绝情况，申请次数剩余：总数3次-当前拒绝数，申请拒绝数大于3次，则不予再次申请）
                 - 审批记录数>=3:跳转《访客预约列表》页面。（提醒用户，审批人拒绝近期访问，谢谢。）
           2. 如果没有，跳转《申请单》页面。
        
3. 进入《用户信息》页面
   《用户信息》填写页面可以参考 股份_访客系统/0.jpg图片。
   包含如下字段：
   - 姓名
   - 手机号
   - 单位
   - 头像照片
   用户信息提交后，跳转到《申请单》页面
4. 进入《申请单》页面
   《申请单》填写页面可以参考 股份_访客系统/1.jpg
   包含如下字段:
   - 被访问人
   - 开始时间
   - 结束时间
   - 访问事由
   
   《申请单》页面点击 被访问人输入框，弹出被访问人查询页面（模态方式）。
    1. 名字输入框
    2. 搜索按钮
    3. 查询结果列表
       1. radio button 单选按钮
       2. 部门
       3. 名字 
    4. 确认按钮（完成选择被访人）
    把选择的被访人名字自动填写到 被访人 输入框中。（请注意此输入框只能是弹出页选择的用户名称信息填入，不能手工填写名字进去）

    《申请单》页面点击 开始时间输入框 或者 结束时间输入框，弹出日期选择控件，可以选择日期。
    提交完，弹出《登记成功》页面。
5. 进入《登记成功》页面
    《登记成功》页面 可以参考 股份_访客系统/2.jpg
    《登记成功》页面点击 关闭 按钮，跳转到《访客预约列表》页面。
6. 进入《访客预约列表》页面
   《访客预约列表》可以参考 股份_访客系统/6.jpg
   包含如下字段：
   - 姓名
   - 单位
   - 头像
   - 有效访问审批记录列表
     - 被访人
     - 访问结束时间
     - 状态（未审批、拒绝、通过）
